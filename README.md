# Portable Tests

Приватный каталог интерактивных тестов: онлайн, как PWA и в виде переносимых HTML-файлов.

## Каталог

- расширенный каталог содержательных, эзотерических и лёгких тестов;
- динамический главный хаб: все карточки, категории, пути и будущие метрики читаются из `tests-registry.json`;
- сбалансированный авторский тест профессиональных интересов: 42 простых действия, 7 направлений и 20 профессий в каталоге рекомендаций;
- тест рабочих суперсил и тест карьерной траектории;
- игровой карьерно-нумерологический тест с раздельным показом ответов и влияния даты;
- калькулятор совместимости «Зодиак + Сюцай» в парном и одиночном режимах с научным пояснением;
- приватный толкователь снов: 47 образов, быстрый поиск, четыре детали и три независимых взгляда;
- интерактивный «3D Кубик судьбы» со встряхиванием телефона, PNG-карточкой и ссылкой на выпавший ответ;
- универсальная локальная анимация сборки результата для гороскопа, Сюцай, числового карьерного теста и сонника;
- мини-тесты о командном вкладе, принятии решений и предпочтительной среде;
- для разделов с традиционными системами есть спокойные пояснения без обесценивания взглядов пользователя;
- русский, қазақша, English, français;
- локальное сохранение прогресса;
- подробные модульные результаты, сочетания ведущих направлений и практические эксперименты;
- Web Share и копирование;
- ссылки на полноценные карточки результатов без передачи отдельных ответов;
- автономный файл `downloads/career-interests.html`;
- PWA для GitHub Pages.
- автоматическая проверка обновлений и кнопка установки новой версии PWA.

Тест предназначен для знакомства с профессиональными интересами. Это не психологическая диагностика и не основание для автоматических решений об образовании или трудоустройстве.

## Локальная проверка

```bash
node scripts/build-standalone.mjs
node scripts/build-quick.mjs
node scripts/verify.mjs
node scripts/verify-registry.mjs
node scripts/verify-interactive.mjs
node astro/dreams/tests/engine.test.mjs
npx serve .
```

## Источники подхода

Формат вопросов о привлекательности видов деятельности опирается на общие принципы модели профессиональных интересов RIASEC и материалы O*NET Interest Profiler. Вопросы, переводы, семь направлений и алгоритм Portable Tests являются самостоятельной авторской реализацией, а не официальной версией O*NET.

- https://www.onetcenter.org/IP.html
- https://www.onetcenter.org/reports/IP_Manual.html

## Приватность

Обычный тест рассчитывается в браузере. Ответы не отправляются владельцу проекта. Будущие тесты по приглашению должны отдельно показывать получателя, состав передаваемых данных и запрашивать явное согласие.
