Deux PortHub : jouer dans le navigateur ou trouver l’APK Android ?

Vous cherchiez peut-être cet autre projet PortHub ? L’application Android est un projet indépendant de RouBR-dev. Nous avons préparé ce guide parce que les deux projets portent le même nom. PortHub.fyi ne développe pas l’application Android et ne distribue pas son APK. Nos jeux et quiz se lancent dans le navigateur. Dépôt GitHub officiel du projet Android.

Puisque vous êtes là, essayez 2048. Vous avez trois vies : vous pouvez en sacrifier une pour découvrir les règles. Jouer à 2048 · Tous les jeux sur navigateur

Questions fréquentes

À quoi sert l’application PortHub pour Android ?

C’est un catalogue de jeux adaptés à Android. L’équipe présente la recherche, les catégories, les fiches avec captures d’écran, la bibliothèque et les liens de téléchargement. Un portage est une version d’un jeu adaptée à une autre plateforme.

Où trouver l’APK et les mises à jour ?

Le bouton de téléchargement du projet renvoie vers GitHub Releases. Cherchez l’APK parmi les fichiers de la version voulue et consultez ses notes. Nous n’hébergeons pas leur APK. GitHub Releases.

Comment installer PortHub sur Android ?
  1. Sur votre téléphone, ouvrez la dernière version publiée par RouBR-dev. Lisez les notes, ouvrez la section « Assets » et téléchargez le fichier .apk. Les archives « Source code » ne servent pas à installer l’application.
  2. Ouvrez l’APK téléchargé depuis votre navigateur ou votre gestionnaire de fichiers. Si Android demande d’autoriser l’installation depuis cette source, vérifiez que le fichier provient du dépôt des auteurs. Cette autorisation concerne l’application utilisée pour ouvrir l’APK.
  3. Touchez « Installer », puis ouvrez PortHub. Vous pouvez ensuite retirer l’autorisation accordée à cette source. Si Play Protect signale un danger, arrêtez-vous et consultez les développeurs.
Comment mettre l’application à jour ?

Comparez votre version à celle de GitHub et lisez les notes de publication. Sauf indication contraire des auteurs, essayez d’installer le nouvel APK par-dessus la version existante. Si Android refuse, vérifiez comment conserver vos données avant toute désinstallation.

Que vérifier si l’APK ne s’installe pas ?

Vérifiez que le téléchargement est terminé, que le fichier se termine par .apk et que l’espace libre est suffisant. Consultez la documentation pour la version d’Android et la compatibilité. Si un message d’erreur apparaît, indiquez-le dans votre ticket GitHub.

Est-ce compatible avec mon téléphone ?

Le README indique Android 5.0 ou une version ultérieure, avec ARM64 / ARMv7. Ce sont les prérequis de l’application. Chaque jeu peut avoir les siens : vérifiez le portage qui vous intéresse.

Ça marche aussi sur iPhone ou PC ?

RouBR-dev indique Android comme plateforme de son application. Pour jouer tout de suite sur téléphone ou ordinateur, vous pouvez lancer nos jeux dans votre navigateur.

Où signaler un problème avec l’APK ou un jeu ?

Pour l’application, ouvrez un ticket dans GitHub Issues. Indiquez le modèle de votre appareil, les versions d’Android et de l’application, et décrivez le problème. Pour un jeu précis, consultez les instructions de son portage. Signaler un problème dans GitHub Issues.

Que compte le compteur de téléchargements ?

Le site de l’équipe additionne les téléchargements d’APK sur GitHub Releases. Les téléchargements répétés peuvent compter : ce n’est donc pas un nombre de joueurs uniques. Site du projet Android.
