Android-қа арналған PortHub жобасын іздеген боларсыз? Бұл — RouBR-dev тобының бөлек жобасы. Атауларымыз бірдей болғандықтан, осы анықтаманы дайындадық. Жиі қойылатын сұрақтар

PortHub Android қосымшасы не істейді?

Бұл Android-қа бейімделген ойындар каталогы. Авторлар іздеу, санаттар, скриншоттары бар ойын беттері, кітапхана және жүктеу сілтемелері барын көрсетеді. Порт — басқа платформаға бейімделген ойын нұсқасы.

APK файлын және жаңартуларды қайдан табамын?

Жоба сайтындағы жүктеу батырмасы GitHub Releases бөліміне апарады. Қажетті шығарылымның файлдарынан APK мен өзгерістер тізімін іздеңіз. Біз олардың APK файлын өз сайтымызда таратпаймыз. GitHub Releases.

PortHub қосымшасын Android-қа қалай орнатамын?
  1. Телефоннан RouBR-dev тобының соңғы шығарылымын ашыңыз. Нұсқа жазбаларын оқып, «Assets» бөлімін ашыңыз да, .apk файлын жүктеңіз. «Source code» мұрағаттары орнатуға арналмаған.
  2. APK файлын браузерден немесе файлдар қолданбасынан ашыңыз. Android осы көзден орнатуға рұқсат сұраса, файлды авторлардың репозиторийінен алғаныңызды тексеріңіз. Рұқсат APK файлын ашқан қолданбаға ғана қажет.
  3. «Орнату» түймесін басып, PortHub-ты ашыңыз. Орнатқан соң сол көздің рұқсатын қайта өшіруге болады. Play Protect қауіп туралы ескертсе, тоқтап, авторлардан анықтаңыз.
Қосымшаны қалай жаңартамын?

Қосымшадағы нұсқаны GitHub-тағы шығарылыммен салыстырып, ескертпелерді оқыңыз. Авторлар басқа жол ұсынбаса, жаңа APK файлын ескі нұсқаның үстінен орнатып көріңіз. Жаңарту өтпесе, ескі нұсқаны өшірмей тұрып, деректерді қалай сақтау керегін анықтаңыз.

APK орнатылмаса, нені тексеремін?

Жүктеу аяқталғанын, файл атауы .apk деп аяқталатынын және бос орын барын тексеріңіз. Android нұсқасы мен үйлесімділікті құжаттамадан қараңыз. Қате мәтіні шықса, оны Issues бөліміндегі хабарламаға қосыңыз.

Телефоныма сәйкес келе ме?

Қосымшаның README құжатында Android 5.0 немесе одан жаңа нұсқа және ARM64 / ARMv7 көрсетілген. Бұл — қосымшаның талаптары. Әр ойынның талабы бөлек болуы мүмкін.

iPhone немесе компьютерде істей ме?

RouBR-dev құжаттамасында қосымшаның платформасы Android деп көрсетілген. Телефонда немесе компьютерде бірден ойнағыңыз келсе, біздің ойындар браузерде ашылады.

APK не ойын ашылмаса, қайда жазамын?

Қосымшаға қатысты мәселені олардың GitHub Issues бөліміне жазыңыз. Құрылғы моделін, Android пен қосымша нұсқасын және не болғанын көрсетіңіз. Белгілі бір ойын ашылмаса, сол порттың нұсқаулығын қараңыз. Мәселені GitHub Issues бөліміне жазу.

Сайттағы жүктеу саны нені білдіреді?

Жобаның санауышы GitHub Releases бөліміндегі APK жүктеулерін қосады. Бір адам бірнеше рет жүктесе, олар да санала алады. Бұл бірегей ойыншылар саны емес. Android жобасының сайты.
